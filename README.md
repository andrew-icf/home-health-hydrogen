# Three Businesses — landing page

Three equal full-height panels
(**Home** / **Health** / **Hydrogen**) that link straight out to each
business. Hover or focus a panel and it takes the spotlight while the
other two quiet down; on phones they simply stack.

## Run it

```bash
npm install
npm run dev
```

Open the printed local URL. For a production build:

```bash
npm run build
npm run preview
```

## Copy

Eyebrow labels, titles, and taglines live in the `PANELS` array in
`src/App.jsx`.
